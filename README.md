# JuttCarsLtd – SQL Server Database Management System

### Project Overview

A relational database management system designed for JUTT CARS LTD, an automotive importation and sales business specialising in importing used vehicles from Japan for resale in Ireland.


The project uses Microsoft SQL Server to design, implement and manage a structured database supporting the vehicle importation, stock management, registration, inspection, repairs and sales processes.

### Technologies
* Database Management System: Microsoft SQL Server
* Query Language: Transact-SQL (T-SQL)
* Development Environment: SQL Server Management Studio (SSMS)
* Database Modelling: Entity Relationship Diagrams (ERD)
* Version Control: Git and GitHub

### Database Features
<ul>
<li>Relational database design and entity relationships</li>

<li>Primary keys and foreign key constraints</li>

<li>Data validation using CHECK, UNIQUE and NOT NULL constraints</li>

<li>Referential integrity and deletion policies</li>

<li>Supplier and consignment management</li>

<li>Vehicle procurement and stock management</li>

<li>Customs clearance and transport tracking</li>

<li>Irish vehicle registration and VRT contractor management</li>

<li>NCT inspections, repairs and garage management</li>

<li>Customer and vehicle sales records</li>

<li>SQL CRUD operations and data retrieval queries</li>

<li>Practical testing of database constraints and relationships</li>
</ul>

### Repository Structure

docs/ – Database documentation, business requirements and ERD.

sql/ – SQL Server database creation, table definitions, constraints, sample data, queries and testing scripts.

### Implementation

The database is developed using T-SQL specifically for Microsoft SQL Server.

SQL scripts are organised into logical stages, beginning with database creation and table implementation, followed by relationships, constraints, sample data and practical testing.

### Project Scope

The initial implementation focuses on Roll-on/Roll-off (RoRo) vehicle shipments, with container shipping arrangements considered for future development.
